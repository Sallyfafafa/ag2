# AG2 vs AutoGen: A Comprehensive Comparison

## Overview

AG2 is the evolution of Microsoft AutoGen, created on November 11, 2024, by the founding team and core contributors of AutoGen. AG2 is not merely a simple fork but represents a comprehensive upgrade and refactoring of the original AutoGen framework.

## Core Differences

### 1. Revolutionary Governance Changes

**AutoGen (Microsoft)**
- Microsoft-led development and maintenance
- Corporate-driven governance model
- Relatively closed decision-making process

**AG2 (AG2AI)**
- New open governance organization [AG2AI](https://github.com/ag2ai)
- Community-driven development model
- Invites collaborators from all organizations
- Transparent decision-making process

### 2. Significant License Change

**AutoGen**: MIT License
**AG2**: Apache 2.0 License (from v0.3 onwards)

**Significance of this change:**
- Enhanced commitment to open-source collaboration
- Additional protections for contributors and users
- Better enterprise-grade usage guarantees

### 3. Project Vision and Positioning

**AutoGen**
- Primarily positioned as a multi-agent conversation framework
- Focused on LLM workflow orchestration

**AG2**
- Positioned as "Open-Source AgentOS for AI Agents"
- Grander vision: building a complete agent operating system
- Not just a framework, but an entire ecosystem

### 2. API Design Improvements

**New LLMConfig System:**
```python
# AG2 new-style configuration
from autogen import LLMConfig

llm_config = LLMConfig.from_json(path="OAI_CONFIG_LIST")
with llm_config:
    assistant = AssistantAgent("assistant")
```

**Enhanced Context Management:**
- Better configuration management

## Migration Guide

### Migrating from AutoGen to AG2

1. **Installation Upgrade:**
```bash
# Upgrade from autogen
pip install -U "autogen[openai]"
# or
pip install -U "ag2[openai]"
```

2. **Code Adaptation:**
Most existing code requires no modification, but we recommend using the new LLMConfig system:

```python
# Old way (still supported)
config_list = [{"model": "gpt-4", "api_key": "your-key"}]

# New way (recommended)
from autogen import LLMConfig
llm_config = LLMConfig.from_json(path="OAI_CONFIG_LIST")
```

3. **Adopting New Features:**
- Use structured outputs
- Adopt new tool registration methods
- Leverage MCP integration capabilities
